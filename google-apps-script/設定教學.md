# 開通「大家的感恩聖誕樹」設定教學（約 10 分鐘）

完成後，同仁勾選「🌍 我願意分享」的留言會存進你的 Google 試算表，所有人都看得到。
沒勾選的留言仍只存在各自的瀏覽器，不會上傳。

---

## 步驟 1：建立試算表與程式

1. 用 Google 帳號到 <https://sheets.new> 建立新的試算表，命名例如「SEL 聖誕感恩留言」。
2. 點上方選單 **擴充功能 → Apps Script**。
3. 把編輯器裡原本的內容全部刪除，貼上 `Code.gs` 的全部內容，按 💾 **儲存**。

## 步驟 2：部署成網頁應用程式

1. 右上角點 **部署 → 新增部署作業**。
2. 點齒輪 ⚙️ → 選 **網頁應用程式**。
3. 設定：
   - **說明**：聖誕感恩留言
   - **執行身分**：**我**
   - **誰可以存取**：**所有人**
4. 按 **部署** → 依指示 **授權存取**（會出現「Google 尚未驗證這個應用程式」→ 點「進階」→「前往（不安全）」→ 允許；這是你自己寫的程式，屬正常提示）。
5. 複製出現的 **網頁應用程式網址**（結尾是 `/exec`）。

> 若使用醫院的 Google Workspace 帳號，「誰可以存取」可能沒有「所有人」選項，請改用其他帳號或洽資訊室。

## 步驟 3：把網址貼進網頁

打開 `index-static.html`，搜尋：

```js
var API_URL = '';
```

改成（貼上你的網址）：

```js
var API_URL = 'https://script.google.com/macros/s/xxxxxxxx/exec';
```

存檔後上傳網站即完成 🎉
（開通後，範例吊飾會自動消失，樹上只會顯示真實的分享留言。）

## 日常管理

| 想做的事 | 怎麼做 |
|---|---|
| 隱藏不當留言 | 在「感恩留言」分頁，取消勾選該列的 **顯示**，1 分鐘內就會從大家的樹上消失 |
| 永久刪除 | 直接刪除該列 |
| 改成「先審核再公開」 | 在 Apps Script 把 `NEED_APPROVAL = false` 改成 `true` → **部署 → 管理部署作業 → ✏️ 編輯 → 版本選「新版本」→ 部署**。之後新留言預設不顯示，勾選「顯示」後才公開；留言者自己會看到「⏳ 審核中」 |
| 看大家送出的溫暖 | 「感恩留言」分頁的 **溫暖數**（H 欄）就是每則感謝收到的「溫暖 +1」累計 |
| 活動結束後備份 | 試算表 **檔案 → 下載 → Excel / CSV** |

- **同仁不能刪除留言**，網頁上沒有刪除按鈕，程式也會拒絕刪除請求；只有管理者能在試算表刪除該列或取消勾選「顯示」。
  （若日後想開放同仁刪除自己的留言，把 `Code.gs` 與 `index-static.html` 裡的 `ALLOW_USER_DELETE` 都改成 `true`，並重新部署。）
- 修改 `Code.gs` 後，一定要用「管理部署作業 → 新版本」重新部署，網址不會變。
- 留言內容會自動防止被試算表當成公式執行；每則最多 200 字、署名 20 字。

---

## 已經部署過舊版程式？

若你在加入「溫暖 +1」之前就部署過，請把 Apps Script 裡的內容整個換成新版 `Code.gs`，
再到 **部署 → 管理部署作業 → ✏️ 編輯 → 版本選「新版本」→ 部署**（網址不變，網頁不用改）。
舊的「感恩留言」分頁可以繼續用，第一次有人按溫暖時會自動寫進 H 欄。
